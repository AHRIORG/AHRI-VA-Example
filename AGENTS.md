# Data-free development

Develop source code, documentation and invented teaching fixtures in this account. Test software using invented records only.

Never read or process participant records in any format, private contracts or reports, raw logs, individual predictions or fitted models. Only the user runs real-data commands under the separate analysis account and releases reviewed aggregates. Never launch an agent in that account.

Keep actual-input assumptions unresolved until the user reviews them privately. Return reviewed, tested code for execution in the analysis account. Instructions and Git ignores do not enforce access controls.
